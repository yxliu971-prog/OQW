# OQW 便携版：数据来源与导入规则

启动方式见根目录《先读我》。以下为数据覆盖和字段约定。

## 实际接入范围与来源

以下数量是本机成功快照，不是覆盖承诺；网站变化后数量可能改变。

| 数据源 | 已读取 | 默认检查周期 | 实际用途 |
| --- | ---: | --- | --- |
| chemicals 开放 HSP 汇编 | 1,211 条 | 每周 | 三项汉森参数；原始 Pa^0.5 除以 1,000 转为 MPa^0.5 |
| US EPA SCIL 的 Solvents 分类 | 117 条 | 每天 | 保留原始图标分类、附注和显式 OQW 映射 |
| PubChem 常用溶剂 | 18 条 | 每周 | 按 CAS 读取结构；NIOSH/ICSC 无歧义沸点和闪点 |
| ECHA SVHC | 0 条 | 停用 / 手动 | 本机自动访问 HTTP 403；没有已核验的稳定解析器，未纳入评估 |

合并去重 **1,277 条物质**，其中 **51 条同时具备 HSP 和绿色分类分值**，17 条有已解析沸点、13 条有已解析闪点。
HSP 数据源没有逐条测量温度，因此温度保持空值；只有 CAS 的记录暂以 CAS 作为名称。
无可靠来源的 GHS、处理成本、工艺安全、能源效率等字段保持未知，不由公开分类猜测。
用户按名称查询时使用精确名称，推荐优先输入 CAS。

公开来源：

- EPA：[Safer Chemical Ingredients List](https://www.epa.gov/saferchoice/safer-ingredients)。仅导入功能分类为 Solvents、具有有效独立 CAS 的条目；不在清单不等于不安全，条目也不是产品认证。
- HSP：[chemicals 原始 TSV](https://raw.githubusercontent.com/CalebBell/chemicals/master/chemicals/Misc/ruben_manuel_hansen_solubility_parameters.tsv)、[软件汇编许可](https://github.com/CalebBell/chemicals/blob/master/LICENSE.txt)、[原始论文 DOI](https://doi.org/10.1007/s42452-022-04959-4)。MIT 软件许可不意味着全部被引用文献自动采用相同许可，记录保留原始出处。
- PubChem：[PUG REST](https://pubchem.ncbi.nlm.nih.gov/docs/pug-rest)、[下载与数据许可说明](https://pubchem.ncbi.nlm.nih.gov/docs/downloads)。保留贡献者物性出处，不把不同贡献者的聚合危害信息转为官方分数。
- ECHA：[官方候选清单](https://echa.europa.eu/candidate-list-table)。可在有访问条件时下载官方资料，按本系统模板整理并作为独立当地规则导入；必须核对发布日、用途、浓度与适用条件。

**评分口径**：兼容字段名 `gsk_score` 的范围仍为 1–10，但本次 EPA 数据使用的是 **OQW-SCIL-v1**：绿实圆 9、绿半圆 7、黄三角 4、灰方块 1。此映射是 OQW 的透明筛选规则，**不是 EPA 数值评分，也不是 GSK 官方评分**。原始图标、附注、方法名称随记录保存。评分方法不同的记录不作跨方法的“绿色程度提升”比较。

GSK / ACS 指南尚未取得适合本系统分发的完整、可核验机器数据和许可，因此本版没有把抓取失败或示例数值包装为官方生产数据。

## 添加个人资料或当地规则

1. 点“添加数据集”，填写名称、用途（个人 / 企业或当地要求）、数据类型、地区、来源与依据、使用许可、版本。
2. 下载 CSV / JSON 空白模板。CSV 使用 UTF-8，JSON 使用记录对象数组。文件最大 2 MiB、最多 10,000 行。
3. 上传文件，点“验证并预览”，检查记录样例和重合 CAS。
4. 点“确认导入并应用”。数据只保存在本机数据库；不会发送给公开数据提供方。
5. 在“个人 / 当地数据”中查看版本、停用、重新启用，或上传同一数据集的新版本。

支持列名映射，例如 `{"CAS号":"cas","物质名称":"name"}`。映射从原字段名指向标准字段名，未知字段或重复映射会报错。PDF、Word、Excel `.xlsx` 和自然语言法规文件需要先整理为结构化 CSV/JSON，本版不自动解读法律文本。

溶剂最低字段为 `cas,name`。可选 `smiles,boiling_point,flash_point,delta_d,delta_p,delta_h,hsp_temperature_c,ghs_codes,gsk_score,raw_scores,excluded`。
HSP 三参数必须同批提供，单位 MPa^0.5；温度、沸点、闪点单位 °C。`gsk_score` 有值时必须填写准确的评分方法与版本，范围 1–10 且越高越绿色，不会自动识别原表方向或算法。

当地规则最低字段为 `cas,name,rule_code,rule_type,warning`。可选 `conditions,severity,effective_from,effective_to,exclude_from_recommendations,active`。

- `rule_type`：`advisory`、`restriction`、`authorization`、`svhc_candidate`。
- `severity`：`info`、`warning`、`danger`；这是界面提示级别，不是法定分类转换。
- 日期：`YYYY-MM-DD`。过期或未生效规则不触发当前预警。
- 布尔值：`true/false`。只在明确需要排除推荐时填写 `exclude_from_recommendations=true`；SVHC 候选身份本身不会被自动解释成禁用。
- `conditions`：写明地区、用途、浓度、工艺和例外条件。系统展示规则并按日期/启用状态筛选，尚不能判断自然语言条件是否满足，也不按用户位置自动切换规则。

危害规则可以独立于物性表存在：仅有当地规则的 CAS 也能在评估中触发提示，但没有的物性不会自动生成。

覆盖行为：公开来源优先级固定 10/20/30/40；个人来源可设 100–999，数值大的后应用；同值按数据集 ID 排序。**缺少列保持低优先级数据；显式空值会清空对应可空字段**，因此不准备修改的列应删除。危害规则按来源和规则号并存，个人资料不会抹掉公开规则。

上传前预览保存 24 小时。预览后如果该数据集已经变化，提交被拒绝，需重新预览。同一数据集不能由溶剂类型改成危害类型，应新建另一数据集。
更新是整份快照替换，旧版有而新版没有的记录会从该来源的当前覆盖层移除；历史版本仍可回滚。可以停用数据集，当前 UI 未提供永久删除历史版本。

## 个人远程来源

勾选“从 HTTPS 数据地址定期读取”，填写原始 CSV/JSON URL。新来源先保持停用，先“立即更新”检查快照，再启用。周期在其卡片“更新设置”中调整。远程来源的快照版本由检查时间和内容摘要生成。

只接受公网 HTTPS 443，不允许账户密码 URL、内网 / 回环地址或 HTTP 重定向。下载连接固定到通过校验的 IP，保留 TLS 域名验证，避免 DNS 重绑定。页面和日志不显示查询令牌，但原始源地址会保存在本机数据库，应避免给其他人分享数据库。
本机代理若把任意域名解析为保留的 Fake-IP，自定义地址会被拒绝。请通过代理设置让相应域名返回真实公网 DNS，或改用本地文件导入；代码内固定核验过的 EPA/HSP/PubChem 端点兼容本机现有代理，不对任意用户地址开放豁免。
