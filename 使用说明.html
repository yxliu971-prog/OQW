OQW · 便携交付版

OQW 绿色智能化学解决方案系统 — Windows 便携交付版 v0.5.0
================================================================

一、拿到这个文件夹后怎么用

1. 如果收到 ZIP，先完整解压，不要在压缩软件内部直接运行。
2. 把整个 G 文件夹放到自己可写的位置，例如 D:\OQW 或桌面。
   不要求保留 G 这个名字；中文、空格路径可以使用。
3. 双击“启动OQW.cmd”。稍等后浏览器会自动打开系统。
   默认地址 http://127.0.0.1:8000；若该端口已占用，启动窗口会显示新的地址。
4. 使用期间保留启动窗口。停止时在该窗口按 Ctrl+C。

内置 Python、RDKit、数据库、前端界面和中文 PDF 字体。
不需要安装 Python、Node.js、npm、VS Code，也不需要账号或 API 密钥。
支持 Windows 10/11 的 x64 电脑；不支持把这个包直接用于 macOS/Linux。
已在本机进行独立路径和隔离环境验收，尚未在另一台实体电脑上验收。

二、这个系统可以做什么

• 输入反应物、产物、质量、溶剂 CAS，计算原子经济性、E-Factor、RME。
• 查看绿色指标、缺失项、溶剂提示、HSP 替换候选和物性对比。
• 导入配方 CSV、粘贴 SMILES 列表、导出中文 PDF。
• 在“数据集管理”里导入个人/企业数据或当地规则，预览、应用、停用和回滚。

本包已带真实公开数据快照，合并 1,277 条物质，可离线使用已有数据。
自动更新需联网。缺失值保留未知，不填造评分、价格或物性。
EPA 分类的 9/7/4/1 是 OQW 明示映射，非 GSK/EPA 官方数值评分。
ECHA 当前未成功自动接入；不表示已覆盖完整 REACH/SVHC 要求。
替换列表是规则筛选候选，不能替代实际反应兼容性验证。

三、如何使用自己的数据

点击“数据集管理”→“添加数据集”，填写来源/许可/版本/地区，上传 CSV 或 JSON。
“导入模板”文件夹和网页提供空白模板。字段规则见“使用说明”文件夹。
先点“验证并预览”，确认后“导入并应用”；个人数据保存在本机，不上传第三方。
不准备修改的字段列应删除；显式空值可能清空对应的底层字段。
首次交付不含开发者的个人评估历史、测试规则或访问令牌。

四、自动更新

系统运行时自动检查到期来源：EPA 默认每天，HSP/PubChem 默认每周。
来源卡片可修改间隔、随机延迟、手动更新或停用。
更新失败保留旧版本，历史评估不会被改写。

如需系统关闭时也检查，可自行双击“安装每日自动更新.cmd”。
它会注册当前 Windows 用户每天本机时间 09:00 的计划任务。
电脑需开机且用户已登录；任务只更新到期来源，不保证断网时成功。
其他机器的任务不会随文件夹复制，需在接收者电脑上自行安装。
移动已安装任务的文件夹后，须在“任务计划程序”删除旧 OQW-Dataset-Daily-Update，
再从新位置安装。若不需要后台任务，可在任务计划程序中禁用或删除该任务。

五、数据在哪里、如何备份

data\oqw.sqlite3：本机全部数据，包括自己导入的数据集和评估历史。
双击“备份我的数据.cmd”，备份写入“备份”文件夹。
恢复时先停止系统和后台任务，把备份复制为 data\oqw.sqlite3，再启动。
升级程序前先备份，不要用新包的空白/初始数据库覆盖自己已有数据库。
使用过的文件夹可能含个人资料；再转交别人前请索取干净交付包。

六、打不开时

• 确认已经解压，runtime、program、data 没有被遗漏，文件夹可写。
• 双击“环境自检.cmd”，它会检查计算、数据库、替换接口和 PDF。
• 浏览器没有自动打开：复制启动窗口打印的网址到 Edge 或 Chrome。
• 报错详情可在 logs\启动错误.log 查看。
• 不要把这个本机单用户工具直接暴露到公网。
