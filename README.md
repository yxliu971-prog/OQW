# OQW 绿色智能化学解决方案系统

本应用是针对于化学实验方案绿色程度的评估系统，它可以根据对应规则对化学实验方案进行打分，并给出绿色可持续的改进建议。具备轻量化，可离线使用，便捷性，可定制化等特点。基于 RDKit、质量衡算、汉森溶解度参数（HSP）和明确的评分规则，同时可以根据个人需要对打分规则进行更改和设计。

本仓库提供 **Windows 10/11 x64 完整便携版**，包含应用源码、已构建网页、Python、生产依赖、中文报告和公开数据种子。无需安装 Python、Node.js 或 VS Code，也无需模型账号或 API 密钥。

绿色与可持续是当今国际的时代背景，对于科研学者更是值得关注。如果此应用能够在科研中帮助到你或为其他开发者提供启发，我将为此感到高兴。

## 下载与启动

1. 在本页点击绿色 **Code** 按钮，选择 **Download ZIP**。
2. 完整解压到自己可写的位置，例如 `D:\OQW`。不要在压缩软件内直接运行。
3. 打开解压后的目录，双击 **`启动OQW.cmd`**。
4. 浏览器会自动打开系统。默认地址为 `http://127.0.0.1:8000/`；端口占用时会选择附近可用端口，以启动窗口显示为准。
5. 使用期间保留启动窗口；停止时按 **Ctrl+C**。

仓库包含完整运行环境，解压后约 210 MB。首次启动不需要联网安装依赖；更新公开数据需要联网。
此便携包适用于 Windows x64，不能直接在 macOS/Linux 上运行。

## 主要功能

- 输入反应物、产物、用量与溶剂，计算原子经济性 AE、E-Factor、反应质量效率 RME。
- 展示六维绿色指标、权重覆盖率、溶剂提示和雷达图。缺失维度显示“未评估”；六维完整时绘制闭合雷达图。
- 按 HSP 距离和可比评分口径筛选溶剂替换候选，比较已知物性。
- 导入配方 CSV、粘贴 SMILES 列表，导出中文 PDF。
- 添加个人/企业数据或当地规则，支持 CSV/JSON 预览、应用、版本回滚、停用和重新启用。
- 对公开或个人 HTTPS 数据源设置检查周期、随机延迟和按需更新。

“填入演示配方”在正式库中使用已有评分依据的示例溶剂，可显示完整雷达图；示例用量及能源/工艺安全值明确标为演示，实际评估应填写自己的数据。

## 数据保存与隐私

仓库 **不包含作者的个人评估历史或个人数据集**。

首次启动会从 `data/public-seed.sqlite3` 自动创建 **`data/oqw.sqlite3`**，自己的评估历史和导入资料保存在这个本机数据库中。重复启动不会覆盖已有数据。

个人数据库、日志、备份及缓存已加入 `.gitignore`，不会通过常规 Git 提交上传。使用 GitHub 网页上传时也应避免上传这些本机文件；不要对个人数据库使用 `git add -f`。
备份会保存到本机的 `备份/` 目录。升级程序前先备份，不要用初始公开数据覆盖自己的数据库。

## 已接入公开数据

| 来源 | 初始快照 | 用途 |
| --- | ---: | --- |
| chemicals 开放 HSP 汇编 | 1,211 条 | 三项 HSP 参数，统一为 MPa^0.5 |
| US EPA SCIL 溶剂分类 | 117 条 | 原始分类、附注与明确标注的 OQW 映射 |
| PubChem 常用溶剂 | 18 条 | 结构和部分有来源的沸点/闪点 |

合并去重的初始公开快照为 **1,277 条物质**。数量会随来源更新变化，未知物性保持未知。

EPA 分类对应的 9/7/4/1 是 **OQW 自定义映射**，不是 EPA 数值评分或 GSK 官方分数。ECHA 自动接入当前受限，不能把本库视为完整 REACH/SVHC 清单。来源、许可、单位和适用条件详见 [数据来源与规则说明](使用说明/数据来源与规则说明.md)。
替换列表用于筛选候选，实际反应兼容性需要后续实验确认。

## 自动更新

工作台运行时会检查到期数据源；EPA 默认每天检查，HSP/PubChem 默认每周。失败保留上次成功版本，历史评估结果不会被更新改写。

需要在工作台关闭后检查，可双击 `安装每日自动更新.cmd`。它为当前 Windows 用户安装每日 **本机时间 09:00** 的任务，电脑需开机且用户已登录。移动文件夹后应重新配置任务路径。
